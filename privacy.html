Privacy Policy

Effective date: 8 October 2026 · Service: Pigwoori AWS Backup

Pigwoori AWS Backup is an owner-operated backup utility using rclone to transfer encrypted application backups to the owner's Google Drive. It is separate from the Pigwoori stock information app and is not offered as a public sign-up service.

1. Information accessed

With the owner's authorization, the utility uses the Google Drive API's drive.file permission to create, list, read, and manage backup files the app is permitted to access. This may include file names, IDs, sizes, timestamps, and the contents of encrypted backup archives. OAuth access and refresh tokens are required to maintain authorized access. The tool does not request Gmail access, contacts, or the full Google Drive scope.

2. How information is used

Authorized Drive data is used only to upload encrypted backup files, verify transfers, retrieve files for recovery, and, if separately enabled, manage backup retention. It is not used for behavioral profiling, advertising, resale, or training generalized AI/ML models.

3. Where information is stored and protected

Backups are encrypted before being uploaded to Google Drive. Credentials and tokens are held in restricted-access configuration on the owner's server. Google Drive stores encrypted backup files. No backup archive or OAuth secret is intentionally published to this website or its GitHub repository.

4. Sharing and third parties

Drive data is not sold or shared with advertisers. Necessary providers include Google Drive (encrypted backup storage) and the owner's hosting infrastructure used to run the backup utility. This public information website is hosted on GitHub Pages, which may process visitor connection information under GitHub's policies. This website does not embed advertising, tracking scripts, analytics, or sign-in forms.

5. Retention and deletion

Backup retention is controlled by the owner. A daily-seven / weekly-four retention schedule is planned but not yet active as of the effective date. Existing manual backups are intended to remain outside automated deletion. When automated cleanup is enabled, deletion is permitted only after upload and integrity checks succeed. The owner may delete stored files in Google Drive and revoke access at any time using Google Account permissions.

6. Access, control and contact

The owner can review or remove backup files through Google Drive, or revoke the application's access in the Google Account security settings. For questions about this policy, use the public GitHub repository issue tracker. Do not post tokens, secrets, passwords, backup contents, or private account details in a public issue.

7. Changes

Changes to data use or backup operation should be reflected in this policy. The current version will remain publicly accessible at this URL.
