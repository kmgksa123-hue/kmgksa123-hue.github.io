Pigwoori AWS Backup

A privately operated utility that uses rclone and Google Drive to store encrypted backups of the owner's Pigwoori application data.

This is not a public app. Only the owner authorizes Google Drive access. This site explains why the backup tool requests Google authorization; it does not ask visitors to sign in.

What the tool does

  • Creates encrypted backup archives of the owner's application data before uploading them to Google Drive.
  • Uses Google Drive's drive.file OAuth permission for files created or opened through the authorized backup tool.
  • Can retrieve backup files to check integrity and support recovery, and will only apply automated retention after configuration and verification.

Data and security

Backup archives are encrypted before upload. Google authorization credentials are kept in restricted-access configuration on the owner's server. No Google Drive content is used for advertising, resale, or AI model training.

Read our Privacy Policy for the types of data accessed, purposes, storage, sharing, and deletion. Terms of Use are also available.
